## Changes

- Both figures use exact 6.5-inch vector canvases, 10.2pt embedded text, identical
  4.6pt open-circle markers with 1pt outlines, 1.25pt lines, and a common palette.
  Marker area no longer varies between squares, diamonds and circles.
- Figure 2 separates line, marker and seed-range artists. Capless 0.65pt range
  segments are drawn above marker interiors so small ranges remain visible;
  these are three-seed minima/maxima, not confidence intervals. There is no band
  shading. All six checkpoint labels and the single-copy control table remain.
- Figure 3 uses the same visual conventions. The 288nt matched-loss replication
  formerly overplotted as larger circles is instead a bottom table at 2.40bits/nt.
  All eight shared-tokenizer entries are retained. Right-panel series have small
  display-only horizontal offsets; no y-values move. Caption explicitly separates
  the absent 288nt k=5 run from conditions whose loss/recovery threshold is unreached.
- Both manuscript versions now describe the panels, table and uncertainty correctly.
  A short NeedsSpace guard keeps the next paragraph from starting as one stranded
  line above Figure 3 in the submission version. The full version is not compressed.
- A source-level caption correction: figures_privacy.series sorts by loss, and
  cost_of_full selects the lowest saved-checkpoint loss passing its threshold.
  Thus 'first reaches' was temporally ambiguous. The text now says lowest saved-
  checkpoint held-out loss with 100% recovery, averaged over seeds. All 21 selected
  source cells have exactly 100% recovery, despite the helper's generic 0.99 threshold.
  Selection code and numerical results are unchanged.
